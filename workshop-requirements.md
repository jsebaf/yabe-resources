# Requisitos del taller

## Recursos de software

- Terminal moderna.
- OpenCode instalado.
- Opcionalmente: Orca, para trabajar con worktrees y gestionar sesiones de OpenCode.
- Git instalado.
- GitHub CLI (`gh`) o GitLab CLI (`glab`) instalados.
- Acceso a un repositorio de GitHub (también es posible utilizar GitLab).
- Docker y Docker Compose para ejecutar la aplicación y sus servicios.

## Competencias esperadas

- Manejo básico de la terminal y del sistema de archivos.
- Conocimientos básicos de Git: clonar repositorios, consultar cambios y crear commits.
- Comprensión elemental de aplicaciones web, APIs y bases de datos.
- Capacidad para leer código, configuración y mensajes de error.
